# Net revenue difference-in-means test for randomized experiments

`net_revenue_test()` analyzes net revenue in a randomized experiment
without ever counting order rows as customers. Given a customer cohort
(treatment assignment and exposure time), a table of paid orders, a
table of (possibly partial) refunds, one common cutoff time, and a fixed
observation window, it builds exactly one net-revenue value per *mature*
customer and feeds those values through `infer`'s native
difference-in-means, permutation, and p-value machinery.

A customer is **mature** when their entire observation window is
observable at the cutoff, i.e. `exposure + window <= cutoff`. Only
mature customers enter the test. Mature customers with no qualifying
orders are retained with a net revenue of zero, so the comparison is
customer-level rather than an analysis of purchasers only. Immature
customers are returned separately and never analyzed.

For each mature customer, only paid orders in the half-open window
`[exposure, exposure + window)` are counted. Net revenue subtracts the
refunds recorded on or before `cutoff` that belong to those counted
orders. Refunds are first aggregated to the order level, so several
partial refunds on one order can never multiply the order's
contribution. All monetary inputs are whole numbers of cents.

The point estimate is the difference in mean net revenue, treatment
minus control. The permutation distribution is generated by permuting
the group label across *customers*, which preserves both group sizes;
orders are never permuted and purchasers are never analyzed on their
own. The reported p-value is two-sided.

## Usage

``` r
net_revenue_test(
  customers,
  orders,
  refunds = NULL,
  cutoff,
  window,
  exposure = "exposure",
  group = "group",
  customer_id = "customer_id",
  order_id = "order_id",
  order_time = "order_time",
  order_amount = "order_amount",
  refund_id = "refund_id",
  refund_order_id = "order_id",
  refund_time = "refund_time",
  refund_amount = "refund_amount",
  treatment = NULL,
  control = NULL,
  reps = 1000,
  seed = NULL
)

# S3 method for class 'net_revenue_test'
print(x, ...)
```

## Arguments

- customers:

  A data frame with one row per customer. Must contain the customer key,
  the assigned group, and the exposure time.

- orders:

  A data frame with one row per paid order. Must contain the order key,
  the customer key, the order time, and the paid amount.

- refunds:

  A data frame with one row per refund, or `NULL` when there are no
  refunds. Must contain the refund key, the order key, the refund time,
  and the refund amount. Refunds recorded after `cutoff` are ignored
  when computing net revenue, but every refund, regardless of timestamp,
  must reference an existing order.

- cutoff:

  A single time: the common as-of time at which order and refund data
  are considered complete.

- window:

  The fixed observation window, as a `difftime` or (for `Date` and
  `POSIXct` times) a positive number of days. It is applied relative to
  each customer's exposure.

- exposure, group, customer_id:

  Column names in `customers` giving the exposure time, the assigned
  group, and the customer key.

- order_id, order_time, order_amount:

  Column names in `orders` giving the order key, the order time, and the
  paid amount (whole cents).

- refund_id, refund_order_id, refund_time, refund_amount:

  Column names in `refunds` giving the refund key, the refunded order
  key, the refund time, and the refund amount (whole cents).

- treatment, control:

  Optional strings naming the treatment and control levels of `group`.
  If only one is supplied, the other is inferred from the two observed
  levels. If neither is supplied, `group` must be a factor and its level
  order is used (the first level is treatment). The estimate is always
  treatment minus control.

- reps:

  A positive whole number: the number of permutation replicates.

- seed:

  Optional single number used to seed the permutation step. The rest of
  the computation is deterministic.

- x:

  A `net_revenue_test` result.

- ...:

  Unused.

## Value

A list of class `net_revenue_test` with elements:

- `estimate`: observed difference in mean net revenue (cents), treatment
  minus control.

- `null_distribution`: a tibble with columns `replicate` and `stat`
  (cents), the permutation distribution from
  [`generate()`](https://infer.tidymodels.org/dev/reference/generate.md)
  and
  [`calculate()`](https://infer.tidymodels.org/dev/reference/calculate.md).

- `p_value`: the two-sided permutation p-value from
  [`get_p_value()`](https://infer.tidymodels.org/dev/reference/get_p_value.md).

- `customers`: one row per mature customer, with the counted order
  count, gross revenue, refunds, and net revenue (all in cents).

- `immature_customers`: one row per customer whose window extends past
  `cutoff`; these are excluded from the test.

- `orders`: the order-level attribution detail, including whether each
  order was counted and its net contribution.

- `groups`: the treatment and control labels and the number of mature
  customers in each.

- `reps`, `cutoff`, `window`: the settings used.

## Examples

``` r
customers <- data.frame(
  customer_id = c("c1", "c2", "c3", "c4", "c5"),
  group = factor(
    c("treatment", "treatment", "control", "control", "treatment"),
    levels = c("treatment", "control")
  ),
  exposure = as.Date(c(
    "2024-01-01", "2024-01-02", "2024-01-01", "2024-01-03", "2024-01-20"
  ))
)

orders <- data.frame(
  order_id = c("o1", "o2", "o3", "o4"),
  customer_id = c("c1", "c1", "c3", "c2"),
  order_time = as.Date(c(
    "2024-01-02", "2024-01-03", "2024-01-02", "2024-01-02"
  )),
  order_amount = c(5000, 2500, 4000, 1000)
)

refunds <- data.frame(
  refund_id = c("r1", "r2"),
  order_id = c("o1", "o1"),
  refund_time = as.Date(c("2024-01-04", "2024-01-05")),
  refund_amount = c(1000, 500)
)

net_revenue_test(
  customers, orders, refunds,
  cutoff = as.Date("2024-01-31"),
  window = 14,
  reps = 100,
  seed = 1
)
#> Net revenue difference-in-means test
#>   Groups: treatment = treatment, control = control
#>   Mature customers: 4 (treatment 2, control 2)
#>   Immature customers (excluded): 1
#>   Observed mean difference: 1500 cents (treatment - control)
#>   Permutation reps: 100
#>   Two-sided p-value: 0.62
```
